Dapur Kilat — a fast timed cooking game in a warm Indonesian kitchen. Orders arrive on the board; grab ingredients from the counter, chop them on the board, cook them on the stove, assemble each dish on the plate in recipe order, and serve it through the window before the customer's patience runs out. Three dishes (Nasi Goreng, Mie Ayam, Sate Ayam), a 150-second shift, three strikes and the shift is over.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Keyboard and mouse, no network, no build step.
